LEADFLOW CLOUD v0.5.1.1 — START HERE

This is a full-stack Next.js starter, not the previous static HTML mockup.
It includes Supabase-backed accounts and workspaces, cloud leads, a public
inquiry form, Google Gmail send + Calendar events, Make/Zapier webhooks, and
optional Resend owner notifications. Provider accounts still need setup.

WHAT YOU NEED
- Node.js 20.9 or newer (Node 22 recommended)
- npm and an internet connection for npm install
- A Supabase project
- A Google Cloud project only if you want Gmail/Calendar

FAST START ON MAC
1. Extract this ZIP.
2. Open the leadflow-cloud folder.
3. Create a Supabase project (an adult should manage provider accounts/billing where required).
4. In Supabase SQL Editor, run supabase/migrations/0001_initial.sql.
5. Copy .env.example to .env.local and fill in the Supabase URL, publishable key,
   server-only secret key, and the two random secrets described in README.md.
6. Run chmod +x run-mac.command && ./run-mac.command
7. Open http://localhost:3000/login if the browser does not open automatically.

The launcher checks Node, installs npm dependencies, and starts the dev server.
The first npm install requires internet. Keep the Terminal window open while using it.
Press Control+C in Terminal to stop the server.

REAL APP CONNECTIONS
- Google: configure OAuth in Google Cloud Console and add the exact callback URL
  shown in README.md. Gmail send and Calendar event creation require consent.
- Make/Zapier: create a webhook in a business-owned account, then connect it in
  the LeadFlow workspace. New lead events are signed with HMAC.
- Resend: optional owner alerts require a verified sender domain and API key.

IMPORTANT
- Never send provider passwords, OAuth secrets, database keys, encryption keys,
  or webhook URLs in ChatGPT. Put them only in your local .env.local file or
  a trusted hosting provider's server-side environment settings.
- Use fictional test information until the security checklist is complete.
- Google Gmail/Calendar scopes may require Google's OAuth app verification before
  unrelated users can connect. Use a configured test user for development.
- QuickBooks, Xero, Stripe, Square, Jobber, Housecall Pro, and similar services
  are not connected in this version.
- A parent/guardian should manage provider accounts, billing, contracts, and
  business setup where required.
